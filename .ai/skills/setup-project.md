# Skill: Project Setup

## Goal
Initialize a new repository with the correct structure and configuration.

## Steps
1. **Structure**: Create core folders (`src`, `tests`, `.ai`).
2. **Context**: Populate `.ai/rules/` from templates.
3. **Config**: Generate `.env.example` and `README.md`.
4. **Dependencies**: Initialize package manager and add core dependencies.
5. **CI/CD**: Add base Dockerfile and GitHub Actions workflow.
