# Skills

Skills are reusable automation patterns or capabilities for the AI assistant.

## Structure
```
.claude/skills/
├── skill-name/
│   ├── SKILL.md         # Definition
│   └── scripts/         # Implementation
```

## SKILL.md Template
```markdown
# Skill Name

## Description
What it does.

## Inputs
- param1 (required)
- param2 (optional)

## Steps
1. Step 1
2. Step 2

## Output
What it produces.
```
