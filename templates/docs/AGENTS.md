# Agents

Agents are specialized personas or subprocesses for complex tasks.

## Types

### Code Reviewer
Reviews code for quality and security.

### Test Runner
Executes tests and ensures coverage.

### Researcher
Explores the codebase and technical docs.

## Agent Pattern
1. Spawn agent with specific role and context.
2. Agent performs task autonomously.
3. Agent returns structured results.
4. Main context synthesizes findings.
